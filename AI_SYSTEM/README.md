# نظام LedgerX AI

## الهدف
نظام تطوير ذكي وآمن لمشروع LedgerX ERP.

النظام يساعد في:
- تنظيم مهام التطوير
- تحليل المخاطر
- توليد Prompts تلقائيًا
- تشغيل التحقق والاختبارات
- حماية النسخة المستقرة من المشروع

---

# الفروع

## النسخة المستقرة
main

## نسخة تطوير الذكاء الاصطناعي
dev-ai

ممنوع التعديل المباشر على main.

---

# مكونات النظام

## AI_TASKS/

نظام إدارة المهام.

### pending/
المهام الجديدة.

### in_progress/
المهام الجاري تنفيذها.

### completed/
المهام المكتملة.

### blocked/
المهام المتوقفة بسبب مشاكل أو نقص متطلبات.

# AI_SYSTEM/

## CHANGE_ANALYZER.md
قواعد تحليل التعديلات قبل التنفيذ.

## impact_matrix.json
تحليل التأثير ومستوى الخطورة.

خريطة موديولات المشروع.

توليد Prompt احترافي تلقائي من المهمة.
